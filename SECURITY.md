# Security

Fieldnote stores tasks only in the browser on this device. There is no account system.

- Do not put secrets, passwords, or access tokens into task text if you share the browser profile.
- Reminders use the Notification API and fire only while the tab is open. They are not a secure scheduler.
- Report vulnerabilities privately to the repository maintainers. Do not file public issues that include exploit detail until a fix is released.
- This project does not accept decompiled third-party code or stolen credentials as contributions.
